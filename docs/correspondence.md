# Implementation correspondence review

This review connects the formal domains to the current Haskell implementation.
It states the boundaries of the implemented rules; it is not a proof of the
whole compiler or a declaration that project acceptance is complete.

The [finer source-correspondence draft](source-correspondence.md) records the
current source-range limitations and proposes occurrence-level tracing. Its
source catalog is implemented; checked/target catalogs and precision levels
remain proposals.

| Boundary | Implementation evidence | Remaining obligation |
|---|---|---|
| YAML and mapping | `Mapping` consumes marked libyaml events, rejects duplicate/unknown keys and aliases, and applies its own YAML 1.2 scalar classification. Versioned profiles have explicit field checks. | libyaml and the profile checks are trusted implementation code, covered by rejection tests. |
| Name resolution | `Compiler` resolves concrete names in checked module scope, deduplicates compiler identities, and requires exactly one candidate. | Agda's scope API is trusted. Display spellings do not establish identity. |
| Dependent roles | `validateModel` enters the actual telescope, raises selected types into that context, and uses Agda conversion with fresh inference metavariables. Unsatisfied constraints and escaping metas reject the mapping. | This instantiates `Mapping.Fits` only for the admitted profiles; unsupported signatures are not semantic incompatibility proofs. |
| Inventory | The backend retains checked signatures, clauses and compiled cases. It closes missing references through imported signatures and then verifies every recorded dependency. | Completeness of Agda's backend interfaces and dependency discovery remains trusted. Source anchors for generated declarations can remain unavailable. |
| Source occurrences | `SourceCatalog` retains structural use paths and disjoint UTF-8 intervals from checked text. Ownership is resolved after root merging, only from unique binding module/span matches. Missing and ambiguous anchors remain explicit. | `SourceOccurrences` proves metadata relocation and repacking preserve identity/distinction, and resolved ownership requires uniqueness. Parser traversal, position conversion, and candidate extraction remain tested adapter boundaries. This does not establish expression alignment. |
| Refusal classification | `Diagnostic` carries explicit categories through native lowering and specialization; `Target` retains per-rule causes and links each refusal to one obligation. | `Diagnostics.Accounting` proves arbitrary reason transformations preserve completeness and strict refusal. Correct category selection and JSON source/model links remain adapter responsibilities, checked by regression and CLI tests. |
| Sharing | `Encoding` has one serialization description with reference and memoized interpreters. `Sharing` checks exact payload equality before reusing a content key and rejects missing/cyclic references. | `Sharing.reconstruction` applies after lookup evidence is established; the hash is not that evidence. Differential encoding and forced-collision tests supplement the review. |
| Multiple roots | `Merge` unions declarations only when their checked source, semantic fields, options and node identities agree. Generated support may acquire a normal source origin. | Agda must check each root consistently; a conflicting snapshot fails instead of choosing one version. |
| Boolean cases | `Target.booleanFunction` admits only Boolean telescopes/results and exhaustive nullary cases. It removes the discriminant, reverses leaf environments for de Bruijn lookup, and rejects additional eliminations. | This is the shape of `BooleanLowering.Cases`. Native literals, references and conditionals must retain their specified SysML meanings. |
| Finite domains | `FiniteTarget.domain` requires a concrete closed datatype and verifies that every constructor has exactly that type, with no payload. The emitter creates a separate enumeration. | SysML enumeration semantics supply a closed carrier with distinct declared values. They do not cover payload types. |
| Finite cases | `FiniteTarget.function` verifies homogeneous finite inputs/results, exact constructor coverage, zero branch arities, binder counts, and in-domain leaves. | `FiniteLowering.lower-preserves` and `native-select-preserves` justify substitution, argument removal and exhaustive selection. Renderer token correctness is additionally checked by the Pilot. |
| Finite relations | `RelationTarget` reads every constructor telescope, retains all witnesses, and maps endpoint variables through the binding-only lexical context to their original witness positions. It checks each result index's domain and emits endpoint equalities. Named rule constraints are combined using existential witnesses and disjunction. | `Relations` supplies both edge directions; `RelationBindings` proves lexical/witness lookup and endpoint-equation preservation for arbitrary binding layouts. Native type extents and existential quantification must denote the corresponding finite carriers; evaluation in the Pilot is incomplete for these quantifiers. |
| Algebraic carriers | `AlgebraicTarget.discover` admits closed acyclic records and sums from complete checked constructor telescopes. Record fields must have corresponding proper projections. `renderShapes` preserves field carriers and constrains selected payload multiplicities and exact type. | `AlgebraicValues` proves product/sum round trips and injectivity. The native attribute semantics and per-field multiplicities must implement the abstract products and admissible slots; arbitrary SysML extensions are outside the generated closed carrier. |
| Algebraic expressions | `AlgebraicTarget.function` checks expression carriers, constructor arities, exact branch coverage, ordered eta fields, proper projection ownership, and every elimination. Payload fields replace their scrutinee in the binding environment. | `projection-preserves`, `payload-binding-preserves` and `dispatch-preserves` justify these operations. Case-tree extraction and the Haskell composition of expression substitutions remain trusted adapter code, tested with heterogeneous nested branches and real Agda extraction. |
| Completion | `Inventory` computes kind-specific requirements separately for each model. `Target` produces either an applicable rule or an explicit textual boundary for every required obligation. `Workflow` returns status 2 for incomplete translation. | These runtime rule checks are evidence gates, not machine-checked implementations of the Agda predicates. No cyclic behavior is admitted by the current native case rules. |
| First-order calls | `AlgebraicTarget.functions` checks canonical callee identities, ordered signatures, complete applications, argument carriers, and every reachable body. It rejects cycles and propagates unsupported callees to callers. | `FirstOrder.program-preserves` establishes correspondence for finite programs whose bodies call only preceding definitions. Topological admission, compiler-term extraction, and native positional invocation remain trusted implementation boundaries, covered by rejection tests and independent target evaluation. |
| Concrete specialization | `Specialize` interprets checked `Abs`/`NoAbs` contexts, recovers omitted type arguments using projection metadata and carrier unification, and removes only resolved static binders. Instance keys retain canonical family/operation identity and ordered arguments. Every instance passes the existing native gates. | `Specialization.substitution-preserves`, the value round trips, and `operation-preserves` justify closed instantiation. Checked-term extraction, demand closure, native naming, and removal of static compiler binders remain trusted adapter code. Concrete uses cannot discharge an open generic mapping root. |
| Open first-order parameters | Automatic declaration roots use distinct symbolic parameter slots and native type-extent inputs. Carriers, calls and constructors retain them; membership and mutual-inclusion constraints check values and bindings. An open root needs its own admitted schema. | `OpenParameters.Transport` proves payload round trips, parameter consistency and preservation of resolution, fallback and concatenation for arbitrary justified bindings. Adapter extraction and rendering remain implementation obligations; CI independently parses emitted bodies and constraints, compares full results, rejects wrong/empty/order bindings and checks a constraint-removal mutation. |
| Indexed family parameters | `Specialize` reads first-order family telescopes and preserves checked applications and runtime indices. Native relation rows and constrained member carriers retain index domains, full payloads and bindings; dependent sums preserve constructor/index relationships. | `FamilyRelations.Transport` proves both payload transport directions, index preservation, selection/wrapping and equality-based reindexing for arbitrary justified bindings. Real self-specification evidence constructors/selectors are checked through independently parsed SysML, including wrong-index/family/binding refusals and a removed-constraint mutation. Generated carriers remain explicit provenance boundaries. |
| Static universes | `Specialize` identifies compiler-registered level primitives, resolves closed zero/successor/maximum expressions, checks type-argument universes, and infers omitted levels only when uniquely determined. Levels remain in ordered instance identities but are absent from runtime signatures. | `UniverseLevels.substitution-preserves`, `resolution-exact`, `Runtime.environment-roundtrip`, and `Runtime.lookup-preserves` justify level evaluation and runtime binder removal. Reading compiler levels, constraint solving, and SysML name resolution remain trusted adapter code with acceptance/refusal tests. |
| Recursive inductive values | Safe positivity evidence and complete checked constructor telescopes justify recursive components. Guarded finite node-count equations retain structure and require decreasing child counts. | `RecursiveValues` proves tree/forest round trips, payload/tag/count preservation and every-child decrease. Extraction, component discovery and native constraint semantics remain adapter obligations checked against the actual emitted core. |
| Captured type indices | Static instance keys abstract runtime indices; carrier indices and helper prefixes retain their actual values and bindings. | `CapturedIndices` proves both prefix injections preserve lookup for all context sizes and environments. Parsed complete `lower` results and invalid/mutated bindings exercise the concrete adapter. |
| Finite indexed values | `AlgebraicTarget` retains finite index expressions in carrier signatures, checks constructor result indices, emits index consistency and fibre constraints, refines case branches, and checks instantiated helper signatures. Omitted runtime indices are recovered from checked principal fibres. | `DependentFamilies` supplies the carrier/fibre correspondence; `IndexedValues` proves constructor/index preservation, fibre round trips, dependent operation preservation and dispatch. Compiler refinement extraction, omitted-argument recovery, and native constraint semantics remain adapter obligations checked by positive and negative implementation tests. |
| Dependent records | `AlgebraicTarget` checks constructor fields in order, verifies each proper projection against the constructor telescope, substitutes actual receiver projections in dependent result types, and checks eta-expanded field types. Known-construction projections reduce before comparing index expressions. | `DependentRecords` proves round trips and prefix, field, and operation preservation for arbitrary preceding tuples and dependent members. Compiler de Bruijn contexts, projection ownership, and native field constraints remain checked adapter boundaries. |
| Specialized indexed records | `Specialize` separates static arguments from typed runtime index expressions, retains runtime binders and omitted-index metadata, and rewrites proper projection identities. Fixed fibres used as type arguments retain their indices in instance keys and names. Native gates recheck all index constraints. | `SpecializedFamilies` proves source/target round trips, index preservation, and operation preservation under equal static interpretations. Extraction, substitution, static inference, and composition with native checks remain adapter obligations covered by combined semantic, refusal, and compiler/native integration checks. |
| Dependent sum payloads | Ordered constructor telescopes admit earlier finite payload references and proper record projections. Construction and case expansion substitute those positions; nested matching propagates branch refinements. Native validity guards dependent equalities by constructor tag and enforces exact active/inactive slot multiplicities. | `DependentSums` proves round trips, tag/member-index preservation, dispatch, result-index observation, and operation preservation. Composition with optional slots and indexed result fibres remains an adapter boundary checked through semantic, refusal, and native evaluation tests. |
| Computed finite indices | A finite-only pass admits complete acyclic helper bodies before shape discovery. Calls remain native; internal expansion and branch equalities check dependent signatures. Specialization preserves and reaches helpers in types. | `ComputedIndices` proves expression substitution, native index evaluation, equality comparison under justified normalization, and transport under branch equality. Compiler extraction and the concrete normalization/refinement algorithm remain adapter obligations checked by semantic, refusal, and native constraint tests. |
| Source contracts | Statement and proof-source requirements retain checked types/clauses and original source. Supported registered-equality statements become native constraints with typed binders, complete premise evidence and admitted expression dependencies. Assumption reporting follows statement and proof dependencies. | Native statements and calculations are counted separately. Independent compiler-shaped fixtures and parsed-output checks cover conclusion evaluation, evidence and binding refusals; retaining or rendering a statement does not prove it in SysML. |
| Artifacts | `Workflow` stages serialization, validates emitted SysML, reserves a fresh destination, and installs the manifest last. Digests identify checked text, mapping, selected library descriptor, generator binary and artifacts. | Filesystem failure can leave an incomplete directory, but not a completed manifest. There is no publication step. |

The formal case proofs quantify over arbitrary environments and substitutions.
Concrete native evaluation tests check an independent implementation boundary;
they do not replace those laws. Source kind, branch arity, constructor identity
and binder order are essential applicability conditions, not conventions inferred
from a project's names.

The native rules still do not cover unsupported open dependent families and arbitrary computed indices,
runtime universe levels and unsupported value parameters, unsupported recursive carrier families and higher-order signatures,
ordered collection operations, or general relation premises. Their checked
representations remain in the inventory and block strict generation whenever
they are required. The `DependentFamilies` carrier theorem is implemented for the finite indexed
fragment described in the translation rules.

The pinned Pilot checks syntax, name resolution and the constraints exposed by
its validator. Its acceptance does not prove semantic equivalence. Evaluation
tests cover generated Boolean and finite-domain calculations, individual
relation endpoint rules, record projections, constructor payload dispatch and
payload admissibility, nested helper calls, and call argument order. The Pilot currently loses invocation context when evaluating
functions returning newly constructed values; a separate evaluator of the target
expression algebra tests that lowering. These checks do not claim complete quantified-relation
evaluation, termination of arbitrary generated code, or end-to-end extraction
correctness.

The checked-to-target adapter is implemented in `Derivation` and the native
lowerers/renderers. Its [additive report](cli.md#checked-to-target-derivations)
retains checked use paths and specialization templates, records native lowering
premises, and emits target spans in the rendering traversal.
`Agda2SysML.Derivations` establishes the abstract origin-composition and
byte/interval laws; implementation tests independently resolve report paths and
slice actual target bytes. Generated structural subtrees and untracked
transformations remain explicit boundaries. The bounded direct-source bridge
adds verified links for explicit first-order clauses and signatures. Signature
transport checks resolved telescope positions across `Abs`/`NoAbs` preparation;
unsupported elaboration and changed specialization remain unavailable. See the
[direct alignment contract](cli.md#direct-source-alignment).
