# Release guide

The current release is an **alpha**, a work in progress that is already useful
within its documented limits. See the [alpha walkthrough](alpha.md) for
implemented functionality, generation from the project's own Agda files,
expected results, and the [interactive SysML guide](interactive-sysml.md).

This path is retained for links from earlier development documentation. It does
not designate a beta release.

Development since alpha, current generated files, verification, and unresolved
work are recorded in the [implementation checkpoint](current-state.md).
